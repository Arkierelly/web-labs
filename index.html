Help & compatibility

Paste: use the HTML tab for a complete standalone page. CSS and JavaScript tabs are inserted into the page when you run it.

Open HTML: loads one HTML file. Import ZIP: imports a bundle of files and lets you choose the entry HTML file. ZIP imports are processed locally in this tab.

Relative assets: regular image, audio, CSS, and script references are rewritten to local object URLs. Some games using dynamic fetch(), module imports, service workers, or complex server routes may not work in this static runner.

Compatibility: WEB LAB catches blocked gamepad API calls and lets the game continue with no gamepad detected, so keyboard/touch controls may still work. This does not emulate a controller.

Sandbox: games run in a separate restricted frame. Persistent storage such as IndexedDB, pop-ups, downloads, network APIs, pointer lock, or fullscreen may be limited by the browser or school policy. Some Unity games log IndexedDB cache warnings but can still run after downloading assets; others may fail if they require storage. The runner cannot bypass network or school restrictions.

ZIP safety: only import files you trust. Large archives may use substantial memory. Encrypted archives and unusual compression methods are not supported.

Privacy: no account, backend, analytics, or cloud save is built into WEB LAB. GitHub Pages serves the app files; game code runs in your browser.
